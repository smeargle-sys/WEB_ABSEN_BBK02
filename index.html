Urutan pilihan saat absen: 1. **Scan QR**: kamera live. Kamera live bisa saja diblokir di web app Apps Script karena aturan keamanan Google. Cara ini juga cocok untuk **scanner barcode Bluetooth** (±Rp150–300 rb), yang paling cepat untuk antrean panjang. 4. **Cari nama → Hadir**, untuk jamaah yang lupa membawa kartu. **Cetak kartu**: login dengan PIN Admin → **Menu Admin** di bawah → **Cetak Kartu QR** → **Cetak**. Kartu juga bisa di-screenshot dan dikirim ke HP jamaah. **Opsional, kamera live dijamin jalan**: hosting `Index.html` di GitHub Pages (gratis). Keterlambatan (ketertiban datang) - **Pengaturan:** tab **Pengaturan → Batas Tepat Waktu** (default **19:45**). Rumus persentase `% Kehadiran = Hadir ÷ (Hadir + Izin + Alpa)` untuk sesi pada periode yang dipilih. - Hanya jamaah dengan **Flag Absen = Y** pada saat sesi ditutup yang masuk hitungan. Jika Flag diubah ke N (misalnya mulai mondok), sesi berikutnya tidak dihitung lagi, tetapi riwayat sebelumnya tetap ada. - Jika **Izin Dihitung Hadir = YA**, rumusnya menjadi `(Hadir + Izin) ÷ (Hadir + Izin + Alpa)`. - Kategori: **Kurang** < ambang kurang ≤ **Perlu Perhatian** < ambang perhatian ≤ **Baik**. - **% Tepat Waktu** = (Hadir − Terlambat) ÷ Hadir. **% Terlambat** = Terlambat ÷ Hadir. Keterlambatan **tidak mengurangi % kehadiran**; jamaah yang terlambat tetap dihitung hadir. ## F.
